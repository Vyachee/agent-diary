# Как участвовать

## Что пригодится

- Скрипты по спецификации из [INSTALL.ru.md](INSTALL.ru.md): `sync.sh`, `watch.sh`, `day.sh`, `board.py`,
  `chat.py`, `setup.sh`, с проверками из раздела «Приёмка».
- Адаптеры трекеров (MCP-сервер и `tracker_pull.py`) для Jira, YouTrack, Linear, GitHub Issues, GitLab Issues.
- Поддержка мессенджеров кроме Telegram.
- Проблемы, на которые вы наткнулись в команде, и правило, которое их решило. Это идёт в «Типичные ошибки».
- Переводы. По умолчанию английский, русский — в `*.ru.md` и `templates/ru/`. Новый язык называется так же
  (`*.<язык>.md`, `templates/<язык>/`) и добавляется в строку выбора языка в начале каждого файла.

## Правила

- Перед крупной правкой заведите issue: что меняете и зачем.
- Один PR — одна тема.
- Примеры только выдуманные: без настоящих компаний, людей, адресов, токенов и задач.
- Скрипты — bash или python3 только со стандартной библиотекой.
- Меняете документ — обновите другие языки или напишите в PR, что их надо обновить.
- Вклад принимается под лицензией [MIT](LICENSE).
